# Polish localization update

This archive contains the XOD IDE source with an additional batch of Polish UI translations.

Updated areas include:
- workspace selection and creation dialogs
- Arduino board selection, serial-port selection, and upload dialogs
- project browser context menus and project publishing/preferences dialogs
- debugger messages and status text
- compilation, upload, dependency, cloud, and error notifications

Technical identifiers, board names, file extensions, command-line output, and code syntax are intentionally preserved where appropriate.

This is an incremental localization pass, not a guarantee that every user-facing English string has been translated. Build and smoke-test the application before replacing your working installer.
